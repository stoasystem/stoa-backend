## Answer

2026-09-05 用户实时确认首版真实验收范围：

- 必须覆盖登录与角色、聊天与上传、真人老师完整答疑、家长周报、练习复习、权限及账号删除。
- 支付功能暂时不测试；关闭态及 Stripe test-mode 完整支付均不属于首版验收。未来若恢复支付能力，应通过新的决策票据重新确定测试范围与门禁，不能援引本决议跳过验证。
- 原生移动端与仍属 Demo 的能力不纳入首版真实验收。

该范围是后续门禁、稳定性和实施顺序的输入；本轮没有执行其中的测试或改变产品行为。
