# v9.0 Current Implementation, Test, Infrastructure, And Security Gap Audit

## Decision

The current decision is **HOLD**.

Phase 477 remains paused after two of four discussion areas. No `477-CONTEXT.md`
or `PLAN.md` may be created from this audit. Phase 474 is also not eligible to
continue from an assumption that its current infrastructure source is safe: its
locked documents and executable repositories materially disagree.

No deployment, provider mutation, production operation, broad cleanup, or
feature implementation occurred during this audit.

This report is a forward-only successor to
`.planning/v9.0-MILESTONE-AUDIT.md`; it does not rewrite the July 30 snapshot or
historical Phase 472, 473, and 475 verification artifacts.

## Executive Findings

1. The repository contains substantial, tested backend safety and consistency
   primitives, and the current backend suite is close to green: **3155 passed,
   1 failed**. The single failure is a wall-clock-dependent test, but it still
   prevents a zero-failure current-candidate claim.
2. Frontend release-hardening is real and currently green: lint, all TypeScript
   projects, 35 release-contract tests, 18 verifier-contract tests, and the
   production build pass. Ordinary component tests are not green, and those
   gates do not prove live backend compatibility.
3. Infra has useful versioning, Object Lock, alias, and served-release
   primitives. Its **12 passing topology tests enforce the obsolete production
   topology**, while Ruff and CDK assembly fail and the staging role can reach
   production targets.
4. All five required current cross-repository flows are broken. The most common
   pattern is not missing code; it is an implemented backend primitive consumed
   through the wrong frontend path/schema or hidden behind synthetic success.
5. The latest Teacher decision is not represented in checked-in requirements,
   roadmap text, backend runtime, frontend runtime, or tests. Historical
   invitation evidence remains valid only for the superseded policy.

- Canonical active runtime roles are `student|parent|teacher|admin`; the Teacher
  terminology gate consumes all 13 `tutor` occurrences as negative or historical
  reconciliation evidence and finds no active backend alias.
- Central actor/resource authorization, token validation, upload/privacy,
  attempt-before-answer, durable conversation commands, question idempotency,
  takeover, relationship, rate, mistake-answer, notification, and deletion
  primitives exist. Their phase-level independent verification is historical;
  the current focused 14-module regression gate still passed **564/564**.
- Conversation regular and pseudo-streaming routes share a strict
  `idempotencyKey`, typed attachment-reference, extra-forbid command boundary and
  durable fingerprint/replay implementation.
- Route authorization inventory and client error-action generators pass their
  current `--check` gates.
- Backend global logout calls Cognito global sign-out and does not report local
  clearing as success when the provider fails.

Current limitations are material: the complete suite is not green, the current
HEAD is not bound to the historical formal receipts, and backend-only success
does not prove Web integration.

### Frontend: substantive current evidence

- The served-release/runtime bootstrap blocks rendering until configuration is
  accepted; alternate `VITE_*` truth and demo/MSW/fallback flags are disabled by
  the release contract.
- `npm run lint`, all application/node/Vitest type projects, 35 release tests,
  18 verifier-contract tests, and the production build pass.
- Password login, email-confirm/resend calls, base conversation routes, and some
  `/teachers` request/detail adapters are connected at the route level.
- The latest remote commit changes the canonical TypeScript role value to
  `teacher` and moves many API paths from `/tutors` to `/teachers`.

These are foundation results, not product completion: ordinary component tests
fail, the E2E harness is intercepted or cannot cross the current startup barrier,
and multiple real requests return 404 or 422.

### Infrastructure: useful primitives, wrong authority

  tested with 90-day artifact and 2555-day evidence governance defaults.
- Lambda published-version/alias, bounded prefix, versioned
  `/served-release.json`, exact-ref workflow, and dist-manifest verification
  primitives exist.
- `uv lock --check` and 12 release-topology tests pass.

These tests do not establish deployability or policy compliance. They instantiate
and assert the former production topology rather than the locked staging-only
contract.
